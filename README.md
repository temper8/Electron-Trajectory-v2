# Electron-Trajectory-v2. Particle Tracing Solver 

Python-проект для моделирования траекторий заряженных частиц (**guiding center**) в магнитном поле токамака. 

Проект позволяет рассчитывать орбиты частиц, анализировать их гармоники и строить сечения Пуанкаре для изучения динамики плазмы.

## 🚀 Быстрый старт

### 1. Установка менеджера пакетов `uv`

```bash
# Linux/macOS
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 2. Создание виртуального окружения и установка зависимостей

```bash
# Создаем окружение и устанавливаем зависимости
uv sync
```

### 3. Запуск симуляции

Запустите основной скрипт, передав имя файла конфигурации (без расширения `.toml`) через `uv run`:

```bash
uv run solver.py short
```

Доступные файлы конфигурации находятся в папке `shots/`:
- `short.toml` — короткий расчет.
- `base.toml` — базовая конфигурация.
- `long.toml` — длинный расчет.

## 📂 Структура проекта

- **solver.py** — главный файл запуска, реализующий цикл интегрирования уравнений движения.
- **src/** — исходный код модулей:
    - `config.py` — загрузка и парсинг TOML-конфигов.
    - `eqations.py` — система дифференциальных уравнений для guiding center.
    - `env.py` — функции описания магнитного поля и среды.
    - `analyze_harmonics.py` — анализ частот гармоник движения.
    - `poincare.py` — алгоритм построения сечений Пуанкаре.
    - `parameters.py`, `physical_constants.py` — константы и параметры частиц.
- **shots/** — файлы конфигурации `.toml`.
- **race/** — папка для сохранения результатов (HDF5 файлы).

## ⚙️ Конфигурация (`shots/base.toml`)

Параметры задаются в TOML-формате:

```toml
[tokamak]
name = "EXL-50U"
shot_number = 13976
R0 = 0.5 # радиус-фактор и т.д.

[solver]
method = "DOP853"
rtol = 1e-8
atol = 1e-8

[run]
num_it = 1000
delta_tau = 0.1
time_start = 0
